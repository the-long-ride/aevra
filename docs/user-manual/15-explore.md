# Explore Aevra

After onboarding, use the sidebar to explore the control plane:

- **Dashboard** for gateway health and activity.
- **Workspaces** for registered roots and admission mappings.
- **Approvals** for OAuth pairing and operation approvals.
- **Permissions** for remembered capability rules.
- **Sessions** for connected remote sessions.
- **Connectors** for advanced Bearer-token clients.
- **Processes** for managed commands that outlive one request.
- **Changes** for recovery and mutation history.
- **Audit** for security events and integrity verification.
- **Settings** for advanced execution, network, environment, and Cloudflare configuration.
- **Guide** for this manual inside the local dashboard.

Start with read-only operations in a test workspace, then increase permissions only when the workflow needs them.
