# Explore Aevra

After onboarding, use the navigation to explore the control plane:

- **Dashboard** for gateway health, provider-neutral exposure status, sleep-inhibition state, and activity.
- **Workspaces** for registered roots, server-side folder browsing, and admission mappings.
- **Requests** for OAuth pairing and operation approvals.
- **Permissions** for remembered capability rules.
- **Sessions** for connected remote and Admin sessions.
- **Processes** for managed commands that outlive one request.
- **Changes** for recovery and mutation history.
- **Audit** for security events and integrity verification.
- **Settings** for separate MCP/Admin exposure, Keep Awake, execution, command/network policy, environment profiles, secret references, and lifecycle hooks. Creation workflows use focused modals to keep the page compact.
- **Guide** for this manual inside the Web UI.

Start with read-only operations in a test workspace, then increase permissions only when the workflow needs them.
